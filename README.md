# 防衛砲台（仮）

中心に据えた砲台を旋回させ、視界に入った敵だけを撃ち落とす協力型防衛シューティング。
前作「星降る夜をこえて」と同じ世界線の別タイトル。

- 設計：`docs/concept.md`、`docs/superpowers/specs/`
- 実装計画：`docs/superpowers/plans/`

## 遊び方

| 環境 | 旋回 | 発射 |
| --- | --- | --- |
| PC（ひとり） | A/D・←→ | マウスで狙ってクリック（長押しで連射） |
| PC（ふたり） | 1P：A/D・←→ | 2P：マウスで狙ってクリック |
| スマホ | 画面下の ◀ ▶ | 扇形の中をタップ（長押しで連射） |

Esc・P・⏸ でポーズ。

## ローカルで動かす

ES Modules を使っているため、`index.html` をダブルクリックで開いても動かない。簡易サーバーで開く。

```bash
npm run serve
```

http://localhost:8080/ を開く。

## チェック

```bash
npm run check
```

```bash
npm test
```

公開前は必ず両方を通す。

## 方針

- ビルド不要。GitHub Pages にそのまま置く
- `js/game/` は描画に触れない純粋なロジック（`node --test` でテストする）
- キャラクター・敵は図形で描く。AI生成の画像・動画は使わない
