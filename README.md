# 防衛砲台（仮）

中心に据えた砲台を旋回させ、視界に入った敵だけを撃ち落とす協力型防衛シューティング。
前作「星降る夜をこえて」と同じ世界線の別タイトル。

- 設計：`docs/concept.md`、`docs/superpowers/specs/`
- 実装計画：`docs/superpowers/plans/`

## 遊び方

| 環境 | 旋回 | 発射 |
| --- | --- | --- |
| PC（ひとり） | A/D・←→ | マウスで狙ってクリック（長押しで連射） |
| PC（ふたり） | 1P：A/D・←→ | 2P：マウスで狙ってクリック |
| スマホ | 画面下の ◀ ▶ | 扇形の中をタップ（長押しで連射） |

Esc・P・⏸ でポーズ。

画面上中央のミニマップには、視界の扇形と、視界の外を含む全ての敵が点で映る。遠い敵ほど大きく描かれる。

- 敵に体当たりされると残機が1つ減る。敵が撃ってくる弾（直進弾・破片）は残機には関係なく、中心に届くとスコアが50点減る（0点未満にはならない。弾は撃ち落とせる）
- 同時に画面にいる敵（本体）は最大5体まで（敵の弾は数えない）。倒すか、中心に届くと、空いた分だけ新しい敵が出る

## ステージとパワーアップ

- タイトルで「ひとりで」または「ふたりで」を選ぶと、ステージ選択に進む。1面から遊べて、クリアすると次の面が解放される（全7面）
- 2面には、3〜5機が同時に別の角度から来る編隊ドローンが出る。ボスも強化型になる
- 3面から、地面から突き上げてくる敵（盛り上がっている間に倒すと楽）、破片を曲線で飛ばす敵が出る。4面では、一拍おいて突っ込んでくる敵も出る
- 3〜4面のボスBは、姿を消して視界の外から突進してくる。突進の予兆（点滅・警告）を見たら、ミニマップで位置を探して撃ち込むと、突進を止められる
- 5面から、シールドを張った敵（シールドが開く一瞬だけ撃てる）、ワープする敵が出る。6面では、電波を放つ敵も出る（電波が自機に届くと、しばらく撃てなくなる）
- 5〜6面のボスCは、本体と偽像が並び、位置が入れ替わる。偽像は1発で消える。シールドを張っている間は、弾が吸収される
- 7面（最終面）は、これまでの全種類の敵が、偏りなく出てくる
- 最終ボスは、召喚・視界の外からの突進・偽像を組み合わせて攻めてくる。HPが減ると、それらを同時に使う
- 敵を10体倒すごとにゲームが止まり、パワーアップを2択で選べる（クリック・タップ、または 1 / 2 キー）
- パワーアップはステージごとにリセットされる。ゲームオーバーからの「もう一度」は、そのステージの最初からのやり直し

| 種類 | 効果 | 上限 |
| --- | --- | --- |
| 連射速度アップ | 秒間の発射数 +15% | 5回 |
| 攻撃力アップ | 1発のダメージ +20% | 5回 |
| 貫通弾 | 倒した敵を貫通する（+1体ずつ、最大4体に当たる） | 3回 |
| 旋回速度アップ | 旋回の速さ +15% | 4回 |
| 視界拡大 | 見える角度 +8度 | 3回 |
| 残機+1 | 残機が1つ増える | 上限なし（出にくい） |

## セーブ

ブラウザの localStorage（キー `td_save_v1`、中身は version 2）に、設定とステージごとのクリア・最高スコアを保存する。古い形式（v1）は自動で引き継ぐ。

## ローカルで動かす

ES Modules を使っているため、`index.html` をダブルクリックで開いても動かない。簡易サーバーで開く。

```bash
npm run serve
```

http://localhost:8080/ を開く。

## チェック

```bash
npm run check
```

```bash
npm test
```

公開前は必ず両方を通す。

## 方針

- ビルド不要。GitHub Pages にそのまま置く
- `js/game/` は描画に触れない純粋なロジック（`node --test` でテストする）
- キャラクター・敵は図形で描く。AI生成の画像・動画は使わない
