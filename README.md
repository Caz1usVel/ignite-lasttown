# 防衛砲台（仮）

中心に据えた砲台を旋回させ、視界に入った敵だけを撃ち落とす協力型防衛シューティング。ソロ、または2人協力（PC）。PC・スマホ対応。
前作「星降る夜をこえて」と同じ世界線の別タイトル。

- 設計：`docs/concept.md`、`docs/superpowers/specs/`
- 実装計画：`docs/superpowers/plans/`
- 公開の手順：`docs/DEPLOY.md`

## 遊び方

| 環境 | 旋回 | 発射 |
| --- | --- | --- |
| PC（ひとり） | A/D・←→ | マウスで狙ってクリック（長押しで連射） |
| PC（ふたり） | 1P：A/D・←→ | 2P：マウスで狙ってクリック |
| スマホ | 画面下の ◀ ▶ | 扇形の中をタップ（長押しで連射） |

Esc・P・⏸ でポーズ。

画面上中央のミニマップには、視界の扇形と、視界の外を含む全ての敵が点で映る。遠い敵ほど大きく描かれる。砲台は画面の下寄りにあり、奥行きは縦に引き伸ばして表示している。

- 敵に体当たりされると残機が1つ減る。敵が撃ってくる弾（直進弾・破片）は残機には関係なく、中心に届くとスコアが50点減る（0点未満にはならない。弾は撃ち落とせる）
- 体力が減っていると、緑色の「回復の隕石」が一定間隔（40秒）で現れる。撃つと体力が1回復する（最大値まで。届いても何も起きない）
- 同時に画面にいる敵（本体）は最大5体まで（敵の弾は数えない）。倒すか、中心に届くと、空いた分だけ新しい敵が出る
- 盾を張った敵の盾は、弾を3発吸収すると壊れる。電波を放つ敵の電波が届くと、1.5秒間撃てなくなる

## ステージ・エンドレス・日記

- タイトルで「ひとりで」または「ふたりで」を選ぶと、ステージ選択に進む。1面から遊べて、クリアすると次の面が解放される（全7面）
- 2面には、3〜5機が同時に別の角度から来る編隊ドローンが出る。ボスも強化型になる
- 3面から、地面から突き上げてくる敵（盛り上がっている間に倒すと楽）、破片を曲線で飛ばす敵が出る。4面では、一拍おいて突っ込んでくる敵も出る
- 3〜4面のボスBは、姿を消して視界の外から突進してくる。突進の予兆（点滅・警告）を見たら、ミニマップで位置を探して撃ち込むと、突進を止められる
- 5面から、盾を張った敵、ワープする敵が出る。6面では、電波を放つ敵も出る
- 5〜6面のボスCは、本体と偽像が並び、位置が入れ替わる。偽像は1発で消える。シールドを張っている間は、弾が吸収される
- 7面（最終面）は、これまでの全種類の敵が、偏りなく出てくる。最終ボスは、召喚・視界の外からの突進・偽像を組み合わせて攻めてくる。HPが減ると、それらを同時に使う
- エンドレス：終わりのないモード。時間が経つほど、敵の種類が増え、出現が速くなり、敵も速くなる。60秒ごとにボス（A・B・Cのいずれか）が出て、倒すたびに強くなる。ゲームオーバーで、スコアと生き延びた時間が記録される
  - 通常エンドレス：最初から遊べる。序盤は隕石とドローンだけ
  - ハードエンドレス：全7面をクリアすると解放される。最初から多くの敵が出て、ボスも強化された状態で始まる
- 日記：ステージをクリアするごとに、防衛砲手の日記が1つ解放される（全7つ）。タイトルの「日記」から読める。文面は仮
- 敵を10体倒すごと（エンドレスではボスを倒したときも）ゲームが止まり、パワーアップを2択で選べる（クリック・タップ、または 1 / 2 キー）
- パワーアップはステージごとにリセットされる。ゲームオーバーからの「もう一度」は、そのステージの最初からのやり直し

| 種類 | 効果 | 上限 |
| --- | --- | --- |
| 連射速度アップ | 秒間の発射数 +15% | 5回 |
| 攻撃力アップ | 1発のダメージ +20% | 5回 |
| 貫通弾 | 倒した敵を貫通する（+1体ずつ、最大4体に当たる） | 3回 |
| 旋回速度アップ | 旋回の速さ +15% | 4回 |
| 視界拡大 | 見える角度 +8度 | 3回 |
| 最大体力+1 | 最大体力が1増え、体力も1回復する | 上限なし（出にくい） |

## セーブ

ブラウザの localStorage（キー `td_save_v1`、中身は version 2）に、設定とステージごとのクリア・最高スコア、エンドレスの最高スコアと時間を保存する。古い形式（v1）は自動で引き継ぐ。

## ローカルで動かす

ES Modules を使っているため、`index.html` をダブルクリックで開いても動かない。簡易サーバーで開く。

```bash
npm run serve
```

http://localhost:8080/ を開く。

## チェック

```bash
npm run check
```

```bash
npm test
```

公開前は必ず両方を通す。

## 公開

GitHub Pages で公開する。手順と公開前のチェックリストは `docs/DEPLOY.md`。`master` への push で、テストとチェックが走り、通ればデプロイされる（`.github/workflows/pages.yml`）。

## ディレクトリ構成

| ディレクトリ | 内容 |
| --- | --- |
| `js/core` | 設定値、入力、セーブ、進行、音、画面の座標変換などの共通部分 |
| `js/game` | 描画に触れない純粋なゲームロジック（敵、ボス、弾、衝突、出現、エンドレス、パワーアップ） |
| `js/render` | Canvas への描画（背景、敵・ボス、視界、ミニマップ） |
| `js/scenes` | 画面ごとの処理（タイトル、ステージ選択、プレイ、結果、日記、設定など） |
| `js/data` | ステージごとの出現表、日記の文面 |
| `tests` | `node --test` のテスト |
| `tools` | 機械チェック（`check.mjs`）、簡易サーバー（`serve.mjs`） |
| `docs` | コンセプト書、公開手順、設計・実装計画 |

## 方針

- ビルド不要。GitHub Pages にそのまま置く
- `js/game/` は描画に触れない純粋なロジック（`node --test` でテストする）
- キャラクター・敵は図形で描く。AI生成の画像・動画は使わない
